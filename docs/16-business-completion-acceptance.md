# 业务端完成定义与验收清单

本文定义“除设备真实接入和 AI 服务外，业务端完成”的唯一口径。源码存在、接口适配器存在或演示页面可操作，均不等于完成。

## 完成定义

一个模块只有同时满足以下条件，才可以标记为“已完成闭环”：

1. 后端实现状态机、事务、幂等键、乐观锁、租户隔离、角色权限和数据范围校验。
2. 前端提供真实列表、搜索筛选、详情、新增、编辑、启停/删除、冲突提示和刷新操作。
3. Gateway 模式不使用静态演示数据冒充真实结果；长者、成员、床位和目录项均从真实接口选择。
4. 上游记录能够驱动下游流程，完成、异常、取消、退住等结果能回写关联资源。
5. 业务动作写入统一审计；入住、护理、异常、交接和导出事件触发正确通知。
6. 附件、对象存储、异步导出和定时任务具有真实配置、权限控制和失败处理。
7. GitHub Codespaces 或 Actions 完成数据库迁移、构建、单元测试、集成测试、Playwright 和跨租户验收，并保留运行证据。
