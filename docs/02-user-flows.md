# 用户流程

## 运营报表与导出

运营报表 -> 选择开始与结束日期 -> 服务端校验当前机构、报表权限和周期 -> 返回机构级指标 -> 选择导出 -> 服务端创建 `QUEUED` 任务并留痕 -> 工作器生成私有 CSV -> 轮询任务至 `READY` -> 下载时再次校验下载权限并签发 5 分钟地址。任务到期转为 `EXPIRED`，失败转为 `FAILED`，两种状态均不得签发下载地址。

## 基础资料维护

头像菜单 -> 系统管理 -> 基础资料（受授权入口）-> 选择房间、床位或目录分类 -> 查询当前机构可用数据或包含已停用数据 -> 新增/编辑并携带版本 -> 服务端校验机构权限、唯一性与停用前置条件 -> 保存并写入审计。停用房间前先停用其全部床位；停用床位前确认空闲、已清洁且未关联在院长者。入住调度只读取启用房间下的启用床位。

## 注册与登录

机构注册 -> 邮箱或手机验证 -> 创建机构管理员 -> 登录 -> 选择已授权租户 -> 进入工作台。密码错误、账号锁定、租户禁用和权限不足均展示可理解的错误提示，不泄露账户存在性。

## 创建长者记录

长者档案 -> 新增长者 -> 填写基本信息与联系人 -> 保存草稿或提交 -> 护理主管补充风险评估 -> 进入待入住或在院状态。床位尚未确认时不得标记为已入住。

## AI 生成与人工确认

护理人员在评估完成后选择“生成计划建议” -> 服务端以最小必要字段调用模型 -> 返回建议草稿和引用知识条目 -> 人工编辑、确认责任人和频次 -> 发布计划 -> 生成每日任务。AI 输出从不直接生效。

## 任务流转

计划生效 -> 按频次生成任务 -> 执行人开始任务 -> 完成并记录结果，或标记异常 -> 护理主管确认异常处理 -> 班次交接签收 -> 服务记录归档。

## 导出

用户选择范围 -> 服务端校验租户、角色、数据范围与脱敏规则 -> 异步生成文件 -> 写入下载审计 -> 用户在有效期内下载。权限变化后未下载文件立即失效。

## 长者 360 联查

选择长者 -> 读取健康档案与 360 聚合 -> 查看联系人、评估、入住、护理计划、任务和服务记录 -> 编辑健康档案或档案子记录时携带版本 -> 服务端保存或返回 `409` -> 刷新当前长者详情。已上传附件 -> 服务端签发单次短时预览或下载地址 -> 浏览器立即打开，不在客户端状态中保存 URL。评估风险 -> 创建护理计划草稿 -> 计划保存评估引用 -> 后续计划、任务和服务记录在 360 视图中可追溯。

## 入住与床位闭环

创建入住申请 -> 录入评估通过/未通过和结论 -> 通过后进入待安排 -> 选择卫生已准备的空闲床位并预留 -> 确认入住 -> 在院期间可选择目标空闲床位并填写理由调床 -> 退住后原床位进入清洁 -> 录入清洁结果 -> 床位重新开放。每个写步骤均携带版本；评估和调床同时携带幂等键，冲突后刷新当前机构数据。

## 护理执行闭环

发布护理计划 -> 维护启用模板 -> 按服务日期幂等生成任务或手工创建任务 -> 指定执行成员开始任务 -> 填写服务记录完成，或填写异常说明 -> 自动创建异常跟进项 -> 结案异常 -> 选择已完成/已说明异常任务创建并提交班次交接。执行、完成、异常与交接均使用版本和幂等键，冲突后刷新当前机构队列。

## 机构成员与权限

头像菜单 -> 系统管理 -> 选择当前机构成员目录 -> 从 RuoYi 系统账号中选择一名未加入该机构的账号 -> 选择一个或多个启用角色 -> 加入机构。成员角色可在成员行内调整，停用后该成员对当前机构的 Gateway 请求被拒绝；切换机构后重新读取该机构成员与角色，不能显示或编辑上一机构的成员关联。

系统管理 -> 权限策略 -> 选择 RuoYi 角色 -> 查看该角色当前授权菜单数 -> 调整角色数据范围 -> 保存。菜单权限仍在 RuoYi 角色定义中维护，数据范围保存前由 RuoYi 校验操作者的角色数据权限。
