# 设计系统

## 风格

克制、清晰、科技感的养老 SaaS，不使用传统后台左侧导航或大面积营销插画。信息优先，卡片圆角不超过 10px，顶部导航固定表达产品与租户上下文。

## 颜色与排版

基础使用白色、冷中性色和深蓝灰文本；蓝色表示可操作与信息，薄荷绿表示稳定或完成，琥珀色表示需关注，红色仅用于风险与错误。正文最小 12px，紧凑说明最小 10px，标题不使用视口缩放或负字距。

## 组件状态

按钮、筛选、表格行、卡片、输入框必须提供默认、悬停、聚焦、禁用、加载、空、错误和成功反馈。危险操作需要二次确认。状态不能只依赖颜色，须辅以文本或图标。

## 响应式与无障碍

桌面优先展示决策与执行信息；390px 宽度下所有关键流程为单列或紧凑行，禁止横向遮挡。交互控件具备可访问名称、键盘焦点与足够对比度；聊天助手在每次输出时自动定位最新内容。
