# 信息架构

## 应用层级

登录与注册（独立入口）

工作台（顶部导航）

- 机构总览：今日优先事项、入住率、任务、关注长者、设备摘要。
- 长者档案：档案列表、长者 360、评估、计划、服务记录。
- 入住与床位：入住调度、房间、床位、入住确认。
- 照护计划：计划列表、今日执行队列、异常与交接。
- 设备中心：设备概览、告警处置、维护巡检。
- 运营报表：照护质量、床位、设备、导出中心。

头像菜单承载个人中心、系统管理和退出登录；系统管理包括成员与角色、权限策略、租户组织。助手固定于认证工作区右下角，不占主导航。

## 导航原则

保持顶栏 SaaS 导航；业务详情使用返回链路；高频处理在页面内完成，低频长表单使用模态层；移动端保持顶部导航与单列内容顺序。
