# device-service

养老设备领域服务。当前已建立 Spring Boot 入口、标准化遥测模型、厂商适配器接口与告警状态机；尚未接入 EMQX、时序数据、设备台账或设备命令。

## 接入规则

设备先通过 EMQX/MQTT 与厂商协议适配器进入本服务。每个适配器将原始载荷标准化为 `DeviceTelemetry`，再由领域规则生成设备状态或告警。设备不得直接写入业务数据库，也不得调用 `care-service`。

## 后续实现顺序

1. 设备产品、设备激活与设备凭证。
2. MQTT Topic ACL、TLS 和租户级设备映射。
3. 设备影子、心跳与在线状态。
4. 高优先级告警、派单、维修、复检与实时推送。
5. 高频遥测进入独立时序库。
