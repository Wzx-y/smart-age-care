# RuoYi Cloud Upstream Baseline

This directory contains an in-repository snapshot of the official RuoYi Cloud `springboot3` branch.

- Upstream repository: `https://github.com/yangzongzhuan/RuoYi-Cloud.git`
- Branch: `springboot3`
- Pinned source commit: `cd323dfee84862dd887d080ca8782369719b2bdc`
- Upstream version: `3.6.8`
- Platform baseline: Java 17+, Spring Boot 3.5.14, Nacos 3.x
- License: retain the upstream `LICENSE` included in this directory.

The nested `.git` directory was intentionally removed. This keeps the platform snapshot in the same future GitHub repository as the aged-care services. Upstream updates must be fetched into a temporary directory, reviewed, and merged deliberately; do not overwrite local aged-care integration files.
